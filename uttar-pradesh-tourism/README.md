## Uttar Pradesh Tourism Website (Next.js + TypeScript + Framer Motion)

### Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

### Pages
- `/` Home page with hero, side navigation, stats cards, and featured cards.
- `/:category` Dynamic tourism category pages:
  - `beaches`
  - `hill-stations`
  - `forts`
  - `wildlife`
  - `religious`
  - `culture`
